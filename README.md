## Installation (Run Locally)
1. Clone the repo:
   ```bash
   git clone https://github.com/shilojeyaraj/Shilo-Personal-Portfolio.git
   cd Shilo-Personal-Portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```
3. Run the development server:
   ```bash
   npm run dev
   # or
   npm start
   ```
4. Open http://localhost:3000 (or the port shown in your terminal)

(Adjust commands to match your project's framework and scripts.)
